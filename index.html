Al's Basement

Support for the offline macOS platformer about a kid, a dream basement, and fifty rooms of trouble.

Controls

  • Move: Arrow keys or WASD
  • Jump / swim / fly up: Space, W, Up, or controller jump button
  • Fire laser: J, K, or configured controller fire button
  • Pause and options: Escape or O

Controller Support

Al's Basement supports keyboard play and common PlayStation, Xbox, and Nintendo controller button layouts. Controller buttons can be remapped from the in-game options screen.

Help

If you run into a problem, include your macOS version, controller model if one is connected, and what room or floor you were playing.

Contact: support page maintained by Alinari Campbell.
